# Third-party notices for the Windows jury package

This directory includes unchanged full license/notice texts available in the installed distributions and the Python 3.12.10 Windows AMD64 distribution. PACKAGE-METADATA.txt preserves package attribution, license metadata, and original project URLs. manifest.json records exact versions, hashes, and runtime/build-only roles.

The application dependencies are exactly the pinned requirements-runtime.snapshot.txt used for this build. PyInstaller and its build dependencies are build tools; they are not additions to application runtime requirements. PyInstaller COPYING.txt contains its full license and the explicit exception for distributing generated applications. Python LICENSE.txt also contains notices for components bundled by the Python distribution. Notices are retained even when a build-only package is not shipped inside the executable.

Application code and the provided anonymized hackathon dataset are separate from these third-party library licenses. No new license is assigned to the provided dataset. This is the authorized jury/demo package for the hackathon; these notices do not grant additional rights to the dataset or imply legal review of every possible redistribution scenario.

Build reproducibility: Python 3.12.10 AMD64; see build-environment.lock.txt alongside this licenses folder. Full license texts, rather than shortened summaries, control their respective components.
