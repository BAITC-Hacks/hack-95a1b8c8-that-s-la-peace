# Актуальное разделение работы

Подробный согласованный пакет заменяет предыдущий предложенный план:

- [Общий план для обоих Codex](prompts/00_SHARED_PLAN.md).
- [Промпт Dinmukhammed](prompts/01_DINMUKHAMMED.md).
- [Промпт друга](prompts/02_FRIEND.md).
- [Единый API-контракт](API_CONTRACT.md).
- [Исходное ТЗ](CASE_REQUIREMENTS.md).

Dinmukhammed: backend, данные, API, ранжирование, объяснения, общий запуск и единоличная интеграция.
Друг: frontend, состояния выдачи, демо и независимая проверка запуска.

Рабочая ветка Dinmukhammed — dev-dimalarp. Имя ветки друга он определяет при её создании. Общая проверяемая версия — integration; main ждёт отдельного указания пользователя. Commit/push личных веток и проверенные объединения в integration разрешены текущим поручением пользователя.

Каждый час до :45 — опубликованные проверенные SHA частей; :45–:50 — проверка и публикация общей сборки одним интегратором. Сам файл не запускает таймер. Последняя рабочая общая версия не заменяется сломанной ради формального дедлайна.

На момент подготовки пакета существуют документы и данные, приложение ещё не реализовано. Все сценарии запуска и проверки в промптах — задания на последующую реализацию, а не отчёт об успехе.
