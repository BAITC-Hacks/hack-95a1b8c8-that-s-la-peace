Codex использован для чтения материалов, анализа CSV, планирования, подготовки документов и проверки их согласованности. Созданы backend и автоматические проверки. Человеческая проверка кода/приложения пока не заявляется. Вклад каждого участника фиксируется после его реальных действий.

Установлены Python 3.12, FastAPI 0.141.1 (MIT), Uvicorn 0.53.0 (BSD-3-Clause), Pydantic 2.13.5 (MIT), Starlette 1.7.0 (BSD-3-Clause). Для тестов pytest 9.1.1 (MIT) и httpx 0.28.1 (BSD-3-Clause). Лицензии прочитаны из метаданных установленных пакетов; исходники библиотек не копируются в репозиторий, их notices поставляются с пакетами. Полные фиксированные версии, включая транзитивные зависимости, — requirements.txt и requirements-dev.txt. Внешних AI API нет; алгоритм детерминированный лексический, описан в ARCHITECTURE.md.

Frontend принят из ветки dev-zoro (fb54b42fba9a1f7a2648cafec76f911d0c0c2de5); сведения об авторстве и проверках — docs/handoffs/ilyas.md. В runtime нет сторонних JS/CSS пакетов, CDN или внешних сетевых запросов. Для интеграционных проверок использованы локальные Node.js 25.2.1, Playwright 1.62.1 (Apache-2.0), Microsoft Edge 153.0.4234.48; их дистрибутивы в Git не добавляются. Проверки, написанные Codex, не считаются человеческой независимой оценкой.
