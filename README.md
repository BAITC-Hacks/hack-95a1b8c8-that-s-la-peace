# That's La Peace — умный подбор подрядчиков

Проект команды для HackAlem AI, трек 06 «Креативные индустрии», кейс #79-lite (Firebird). Цель — подобрать до трёх event-подрядчиков по параметрам мероприятия и дать конкретные объяснения выбора.

Сейчас подготовлены требования, исходный каталог из 66 профилей и комплект координации. Приложение ещё не реализовано; команду запуска, рабочую демонстрацию и результаты тестов добавим после фактической проверки.

## Как начать двум участникам

1. Оба читают [общий промпт](docs/prompts/00_SHARED_PLAN.md).
2. Dinmukhammed передаёт своему Codex [личный промпт backend и интеграции](docs/prompts/01_DINMUKHAMMED.md).
3. Друг передаёт своему Codex [личный промпт frontend и демо](docs/prompts/02_FRIEND.md).
4. Оба соблюдают [API-контракт](docs/API_CONTRACT.md) и работают в разных копиях/ветках.

Рабочая ветка Dinmukhammed: dev-dimalarp. Ветку друга он создаёт сам. Общая проверяемая версия — integration, обновляет только Dinmukhammed. Main не меняется до отдельного решения пользователя.
